## Agent Interpretation

**Problem**: The Makefile's `benchmark`, `eval-best`, and `liveplot` targets hard-code no device flag, so CUDA-capable machines always train and evaluate on CPU unless the user edits the Makefile or calls the scripts directly.

**Approach**: Add a `DEVICE ?= cpu` variable (mirrors the existing pattern for `MAZE`, `SEED`, etc.) and thread it through the three affected targets. `run_benchmark.py` uses `--devices` (plural, comma-separated list); `eval.py` and `liveplot.py` use `--device` (singular) — each target passes the right flag. Also update the help text and `.PHONY`/variable comment block.
